## Your job: place the gym days

You get the plan's hard days and, per week, the days code allows for gym (never the day before a long run or key session; the same day as a key session is fine). Pick `days` (usually 2) from the allowed days, as close to the athlete's usual gym days as the rule permits; if a usual day is not allowed, say where it moved and why.

Give one session per phase present in the plan (base, build, peak, taper): focus, minutes (taper sessions short and light), 3 to 6 exercises with sets x reps. Single-leg work, glutes, calves, hamstrings and core. `mobility_note`: one short tip. No rehab prescriptions.
